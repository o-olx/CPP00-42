# CPP00 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP00 est une introduction au C++ orienté objet.
Il permet de découvrir la syntaxe de base du langage, les classes, les attributs, ainsi que la compilation avec `c++`.

---

## 🛠️ Notions abordées

* Compilation en C++
* `iostream`
* Classes et objets
* Attributs publics / privés
* Fonctions membres
* Constructeurs / destructeurs
* `this`

---

## 📂 Exercices

* **ex00** : Megaphone
* **ex01** : My Awesome PhoneBook
* **ex02** : The Job Of Your Dreams *(pas dans le dépôt)*

---

## ⚙️ Compilation

| Commande      | Description                                                            |
| ------------- | ---------------------------------------------------------------------- |
| `make`        | Compile l'exercice et génère un exécutable                             |
| `make clean`  | Supprime les fichiers objets (`.o`)                                    |
| `make fclean` | Supprime les fichiers objets **et** l'exécutable                       |
| `make re`     | Supprime les fichiers objets, l'exécutable, puis recompile entièrement |

# CPP00 - 42 | [ENGLISH VERSION]

## 📚 Description

CPP00 is an introduction to object-oriented programming in C++.
It introduces the basic syntax of the language, classes, attributes, member functions, and compilation using `c++`.

---

## 🛠️ Concepts Covered

* C++ compilation
* `iostream`
* Classes and objects
* Public and private attributes
* Member functions
* Constructors and destructors
* `this` pointer

---

## 📂 Exercises

* **ex00** : Megaphone
* **ex01** : My Awesome PhoneBook
* **ex02** : The Job Of Your Dreams *(not included in this repository)*

---

## ⚙️ Compilation

| Command       | Description                                                      |
| ------------- | ---------------------------------------------------------------- |
| `make`        | Compiles the exercise and generates an executable                |
| `make clean`  | Removes object files (`.o`)                                      |
| `make fclean` | Removes object files **and** the executable                      |
| `make re`     | Removes object files, the executable, and recompiles the project |
